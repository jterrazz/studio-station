## Working from source

```sh
git clone https://github.com/jterrazz/studio-station.git
cd studio-station
make install              # Go modules and the npm half
make build                # .artifacts/go/station
./.artifacts/go/station overview  # run the build without installing it
```

The binary reads nothing from the clone: the catalog's items, the built-in Machinefiles, the dotfiles and the VM recipes are embedded, so any checkout is a checkout to build. Go 1.27+ and npm are the two requirements; `make install` touches nothing outside the checkout. `make provision` puts the build on the machine as the real `station` ([Release](release.md)).

## The make targets

| Target               | Does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `make install`       | Fetch the Go modules and install the npm half (`npm ci`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `make build`         | Build `.artifacts/go/station`, its version stamped from `git describe`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `make build-linux`   | Build `.artifacts/go/station-linux-arm64`, the binary a VM image carries                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `make e2e-binaries`  | Build `.artifacts/go/station` for darwin/arm64 and `.artifacts/go/station-linux-arm64`, both without cgo (the release builds its darwin binary with cgo, [Release](release.md)), where Go is (a Linux workspace): the pair the machine tiers carry, copied to the Mac that runs `specs/machine/run.sh`                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `make lint`          | Both halves: `gofmt -l`, `go tool golangci-lint` and `go tool deadcode` over Go, then `typescript check`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `make fix`           | Every fixer: `gofmt -w ./src ./specs`, then `typescript fix`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `make test`          | `go test ./src/... ./specs/...`, then `typescript test`: the `specs/cli` suite against a fresh build                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `make check`         | `lint`, `test`, `build-linux`, then `menubar-check`: the gate a change passes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `make menubar-check` | the Orbit's and the agent's SF Symbols and the brand marks drawn into `apps/menubar/sources/station-kit/token/symbols.xcassets` (gitignored) by `apps/menubar/scripts/symbols.swift`, then `swift test` over `apps/menubar` (every story drawn offscreen against its PNG goldens), then its bundle; one line of skip without a macOS SDK, a failure then under `STATION_REQUIRE_MENUBAR=1`                                                                                                                                                                                                                                                                                                                                           |
| `make menubar`       | Build `.artifacts/menubar/Station.app`, signed ad hoc; `make menubar-install` copies it to `~/Applications`, `make menubar-uninstall` unregisters its login item and removes it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `make catalog`       | Build the Station Catalog (`apps/menubar/sources/station-catalog`), the dev-only window over every story with its knobs and a live panel, never bundled; `make catalog-open` opens it (the owner's gesture only, `STATION_DESIGN` set shows the prototype's capture beside), `make catalog-export` draws every story headless into `.artifacts/catalog/` (`FILTER=<regex>`), as `StationCatalog --export <dir> [--filter <regex>]` does, and `make catalog-gallery` adds `.artifacts/catalog/index.html`, the gallery to browse offline or on the phone: every story's dark and light images by group, the prototype's capture under them when `STATION_DESIGN` is set, a failing story red with its `.actual.png` beside its golden |
| `make generate`      | Regenerate the projections: the toolbelt skill's rosters, `docs/reference/footprint.md`, the JSON Schemas `schemas/station.catalog.v1.json` and `schemas/station.machinefile.v1.json`, the page fixtures, the menu bar's streams, `src/remote/api/calls.json`, `apps/menubar/stories/INDEX.md` and the Xcode preview of every story, `apps/menubar/sources/station-kit/catalog/Previews.generated.swift`                                                                                                                                                                                                                                                                                                                             |
| `make provision`     | Build, put `station` in `~/.local/bin`, then run `station init`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `make deprovision`   | Remove the provisioned binary                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `make clean`         | Remove `.artifacts/`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

`install`, `build`, `lint`, `fix`, `test` and `check` are the gestures every repository of the estate answers, so a session that never opened this one installs, proves and repairs it the same way; `make install` touches nothing outside the checkout, and putting `station` on the machine is `make provision`'s alone. `make check` is the whole gate, and it fails on the first finding of either half. The Go half runs `golangci-lint` and `deadcode` with `go tool`, at the versions the `tool` directive of `go.mod` declares, so the Go that builds the binary builds its linters and a green run is never a fact about the day it ran. Which linters judge the Go sources, and the four exclusions that carry a reason, are `.golangci.yml`. The TypeScript half is `typescript check` from `@jterrazz/typescript`, whose passes are the toolchain's own [Quality checks](https://github.com/jterrazz/package-typescript/blob/main/docs/reference/quality-checks.md).

## Where a change goes

Most changes are a catalog item, not new code; the rest open one family, and inside it the part their kind of change names ([Architecture](../concepts/architecture.md#the-hexagon-in-each-family)). The folder to open:

| Change                                         | Folder                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| An app or an agent skill `station apps` offers | its item file, `src/catalog/items/<category>/<name>.yaml` (`station.catalog/v1`, [Architecture](../concepts/architecture.md#the-catalog))                                                                                                                                                                                                      |
| What an app keeps on disk, how it is freed     | the `disk:` row of its item file                                                                                                                                                                                                                                                                                                               |
| A setting station applies                      | its item file under `src/catalog/items/` (its values in `sets:`); a new effect, its key in `src/catalog/item.go` and its Applier in `src/settings/adapter/<technology>/`, listed in `src/wire/`'s appliers                                                                                                                                     |
| A checked setting                              | `src/catalog/checked.go`; a new fact, read by `src/settings/adapter/macos/` (the `Inspector`)                                                                                                                                                                                                                                                  |
| A manager `--method` knows                     | `src/catalog/managers.go`; the item that installs it, `kind: manager`                                                                                                                                                                                                                                                                          |
| How a method installs                          | its adapter `src/apps/adapter/<method>/`, in the `Installers` registry `src/wire/apps.go` builds                                                                                                                                                                                                                                               |
| A built-in Machinefile                         | `src/catalog/machinefiles/<name>.yaml` (`station.machinefile/v1`, [Machinefiles](../reference/machinefiles.md)); a new key, its type in `src/catalog/machinefile.go` and its check in `machinefile_decode.go`, then `make generate` for its schema                                                                                             |
| A dev server's port, its label and env         | its item's `ports`, `src/catalog/items/<category>/<name>.yaml`                                                                                                                                                                                                                                                                                 |
| A public route `--via` knows                   | its adapter `src/ports/adapter/<route>/`, in the `PublicRoutes` `src/wire/tailnet.go` builds                                                                                                                                                                                                                                                   |
| A VM image's recipe                            | `src/catalog/images/`                                                                                                                                                                                                                                                                                                                          |
| An application's dotfile                       | `src/catalog/dotfiles/`                                                                                                                                                                                                                                                                                                                        |
| A rule of a family                             | its model, `src/<family>/` (pure: no I/O, no contract)                                                                                                                                                                                                                                                                                         |
| A use case, or a new verb                      | its call in `src/<family>/calls/`, in that family's `All`; its leaf `src/surface/cli/<noun>/<verb>/`; its page in `src/pages/<family>/`; the words of each code it raises in `src/surface/cli/words/`; its stories in `specs/usecases/<family>/<verb>/`                                                                                        |
| A new technology for an existing need          | an adapter `src/<family>/adapter/<technology>/` of that contract, passing its `contract/contracttest/`; chosen in `src/wire/`                                                                                                                                                                                                                  |
| A new need of the world outside                | a contract in `src/<family>/contract/` with its suite, its real adapter, its fake in `src/<family>/adapter/fake/` over a slice of `src/world/`, both wired in `src/wire/` (`world_on.go` for the fake)                                                                                                                                         |
| A new section                                  | its family, its row in `src/core/section/`, its line in the Overview (`src/overview/calls/`), its page and its TUI screen                                                                                                                                                                                                                      |
| An engine job                                  | `src/engine/process/` (the sample job: `src/engine/jobs/`); the rule it applies stays its family's                                                                                                                                                                                                                                             |
| What a page shows                              | `src/pages/<page>/`, then `make generate` for its fixtures                                                                                                                                                                                                                                                                                     |
| What the TUI does on a key                     | `src/surface/tui/screens/`                                                                                                                                                                                                                                                                                                                     |
| What the menu bar shows                        | the `menubar` pages, `src/pages/menubar/` and `src/engine/feeds/`; how they are drawn, the Swift kit in `apps/menubar/sources/station-kit/`; its goldens are drawn by the menu bar VM and rewritten there by `specs/machine/menubar/run.sh <label> --update-goldens` ([the test guide](test.md#the-machine-specs)), never from the owner's Mac |
| A story of the menu bar                        | its line in `apps/menubar/stories/STORIES.md`, its `<id>.story.json` beside it (`station.story/v1`, read by `sources/station-kit/catalog/`), its dark and light goldens in the stories folder of the kit's test data; `StoryCoverageTests` fails on an id with no story or no goldens                                                          |
| The wording of an error                        | its code's words in `src/surface/cli/words/codes.go`; an adapter's error type in `src/surface/cli/kit/failures_<family>.go`                                                                                                                                                                                                                    |

The rules of `specs/architecture/` refuse a change that crosses a boundary; a rule's allowlist only shrinks, so a change that would need a new line in one stops and asks. The linters run with `go tool`, so `make lint` needs no installed linter.

## What a change owes

Four things land in the same commit as the change that makes them true:

- **A catalog change regenerates the projection.** Run `make generate`; the sync test in `make test` fails otherwise, and the sections between the `GENERATED` markers are never edited by hand ([Apps and skills](../reference/apps-and-skills.md)).
- **A change to behaviour carries its spec document.** A new call, outcome, flag, refusal or `--json` key comes with the story that proves it, `specs/usecases/<family>/<verb>/<outcome>.spec.yaml` over a world, and an adapter's new argv with its document in `specs/adapters/<tech>/`; the `coverage` rule fails a call missing a story of an outcome it declares. `TEST_UPDATE=1 npm test` rewrites only the `exit:` and streams of existing documents ([Test](test.md)).
- **A change to behaviour updates its page.** The corpus is where this repository's knowledge is authored; a page left saying what is no longer true is a bug that shipped.
- **A comment states its kind, in both halves.** The default is none; a comment that stays opens with `invariant:`, `hazard:`, `outside:` or `value:` ([A comment states its kind](https://github.com/jterrazz/package-typescript/blob/main/docs/reference/lint-presets.md#a-comment-states-its-kind)). The Go half holds the same law in Go's shapes: a package comment (staticcheck's ST1000 asks for it), and one line of doc above an exported identifier or member, its hover. A kinded comment about an exported function goes inside its body, since ST1020 wants that function's doc to open with its name. `typescript check` reads the configs and scripts, not `.go` files, so on the Go side the review is the gate.
- **A change to a doctrine page updates its skill.** [The stack](../concepts/stack.md) ships as `studio-stack` and [Repo structure](../concepts/repo-structure.md) as `studio-repo-structure`; skills route, they never author.
