# Machine toolbelt

Every studio machine is provisioned by `station` (studio-station). The rosters below are a **committed projection** of the CLI's catalogue (`src/catalog/`), regenerated by `make generate` and kept honest by a sync test. They are exact for what `station` manages, not exhaustive for the machine (other software may exist; `station apps` shows what is actually installed here).

## Reach for these first

Modern replacements are on every machine; prefer them over the defaults:

## Always

- Never edit the generated sections: change the catalogue in `src/catalog/` and run `make generate`.
- The roster is the curated catalogue, not proof of local install state; when an app is missing, `station apps install <name>` puts it on.
- Repo-layout doctrine is not here: see the `studio-repo-structure` skill.
